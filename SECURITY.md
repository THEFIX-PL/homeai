# Security policy

HomeAI can control devices and change Home Assistant configuration, so security reports are taken
seriously.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting: open the **Security** tab of
this repository and choose **Report a vulnerability**. Include the HomeAI and Home Assistant versions, what
you did, what happened, and what you expected.

You will get an answer within 7 days. Fixes for confirmed issues ship in a patch release, with credit if you
want it.

## Supported versions

Only the latest release receives security fixes.
